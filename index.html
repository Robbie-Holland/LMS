Rules

How it works

  1. Register using your name and a unique code of your choice.
  2. Pay the buy-in using the Revolut link.
  3. Wait until your entry is approved.
  4. Pick one team to win in the current gameweek.
  5. You cannot reuse a team in a later week of the same round.
  6. If your team fails, your status changes from Standing to Fallen.
Notes

Before you submit

  • Use the same code each week so your pick matches your entry.
  • Your code can be text or numbers, but it must match the one used at registration.
  • Submit before the deadline shown at the top of the page.
  • If picks are hidden, the board will show “Pick submitted” until reveal is turned on.
